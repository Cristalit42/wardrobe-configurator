# Конфигуратор шкафа

Демо 3D-конфигуратора корпусной мебели: пользователь задаёт размеры и наполнение шкафа, а приложение сразу строит 3D-модель, чертёж с размерами и спецификацию деталей для производства.

## Возможности

- Габариты 600–3000 × 1200–2700 × 350–700 мм, от 1 до 5 секций (минимум 300 мм на секцию)
- Наполнение каждой секции: полки (0–8) или штанга с полкой над ней
- Распашные двери с анимацией открытия, 4 декора ЛДСП
- Чертёж в SVG: вид спереди и сбоку с размерами
- Спецификация деталей (длина × ширина × толщина, количество) и примерная стоимость материалов
- Экспорт: **DXF** (открывается в AutoCAD, КОМПАС, LibreCAD), SVG, CSV, PDF через печать
- Ссылка на проект: вся конфигурация хранится в адресе страницы

## Стек

React 19, TypeScript, Vite, Three.js через React Three Fiber и drei, Tailwind CSS 4.

## Как устроено

- `src/lib/model.ts` — модель шкафа: из параметров получается список деталей с координатами и размерами. Из этого же списка строятся 3D, чертёж и спецификация, поэтому они не расходятся.
- `src/lib/drawing.ts` — геометрия чертежа в миллиметрах (ось Y вверх, как в CAD)
- `src/lib/dxf.ts` — генерация DXF R12 без библиотек: линии, текст, кириллица через `\U+XXXX`
- `src/components/Scene.tsx` — 3D-сцена; three.js подгружается отдельным чанком

## Запуск

```bash
npm install
npm run dev
```
